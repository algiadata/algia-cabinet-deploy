# Docker Desktop

## Objectif

Docker Desktop sera le prérequis principal pour faire tourner ALGIA Cabinet localement sur Windows.

## Étapes prévues

1. Télécharger Docker Desktop depuis le site officiel.
2. Installer Docker Desktop.
3. Redémarrer le PC si Windows le demande.
4. Ouvrir Docker Desktop.
5. Attendre que Docker soit prêt.
6. Lancer ensuite l'installateur ALGIA Cabinet.

## Vérification simple

Avant l'installation, l'utilisateur doit voir Docker Desktop ouvert et actif.

## Message utilisateur

```text
Avant d'installer ALGIA Cabinet, ouvrez Docker Desktop et attendez qu'il soit prêt.
```
