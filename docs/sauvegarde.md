# Sauvegarde

## Objectif

La sauvegarde doit être prévue dès le départ, car ALGIA Cabinet est une application locale.

## Principe

L'utilisateur doit pouvoir conserver une copie de ses données dans un emplacement clair.

## Cible V1

- sauvegarde locale
- dossier de sauvegarde identifié
- procédure simple
- restauration documentée

## Règle produit

Aucune installation locale ne doit être considérée complète sans procédure de sauvegarde.

## Statut

Document de cadrage. Le script de sauvegarde sera ajouté plus tard.
